# Immaculate Grid Engine
A game-agnostic "immaculate grid" style puzzle engine. The public-facing
product built on top of it is branded **GachaGrid** — the repo/engine keep
this genre-descriptive name since that's what the engine architecturally is,
not a naming constraint on the product itself. See docs/ARCHITECTURE.md's
Overview for the full reasoning.

## Status
In development.
